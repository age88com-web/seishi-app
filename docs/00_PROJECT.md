# 御定術数システム

## プロジェクト名

御定術数システム

---

## プロジェクトの目的

本プロジェクトは、伝統術数を正確にデジタル化し、
講義テキストに基づいた排盤を行うことを目的とする。

単なる術数ソフトではなく、
長年研究してきた理論を正確に再現できるシステムを構築する。

---

## 開発方針

講義テキストを仕様書とする。

1080局は検証データとして使用する。

設計を先に行い、その後に実装する。
