## 14. 追記（720マス本転記中の再確認・2026-09-12）

720マス本転記（`docs/takujitsu_jika_720_master.md`）の過程で、7.2節「財局」の除外判断を**撤回**した。

- したがって「財局」は**正式な独立語としてマスターに復帰**する（交貴・日祿・比肩・六甲などと同種の扱い）。
- ただし、この関係（日支×時支の三合・時干の十神から「財局」等の語を機械的に生成する規則）を**一般化してコード実装することは今回行っていない**。原表に現れた場合にそのまま記録するのみ。
