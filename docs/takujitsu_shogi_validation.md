# 擇日象意 答え合わせ・予備検証フェーズ

最終更新：2026-09-09（初版。サンプル40行での予備検証。720行全件照合はまだ
行っていない）

---

## 0. 本ドキュメントの位置づけ

用途判定engine 第1フェーズ（`src/lib/takujitsu/activity/`）が導出する
「吉用事（`positiveSources`）」を、`docs/source/擇日象意.pdf`（720行、
月令×六十干支ごとの宜一覧）のサンプル40行と比較し、どこまで再現できて
いるか・差異が何によって生じているかを調査した結果をまとめる。

**最重要方針**：擇日象意.pdfは仕様ではなく検証資料である。一致させる
ために既存ロジックは一切変更していない（`CalendarEngine`・神殺
occurrence・`resolution`・`activityProfiles`・`evaluateActivities`・
`jianchu`・`shuku28`はすべて今回未変更）。差異は「なぜ違うのか」を
原典（`擇日テキスト.pdf`・`12建除.pdf`）側の規則から調査するに留め、
擇日象意.pdfの結果に合わせるための例外処理・ハードコードは一切行って
いない。720行をコード化する作業も今回は行っていない（前フェーズの
`tests/fixtures/shogi_validation_samples.json`はサンプル抽出のための
中間データであり、本番`src/`には一切書き込んでいない）。

## 1. 検証方法

### 1.1 サンプル選定（40行）

`tests/fixtures/zeyi_shogi_extracted.json`相当の720行データ
（既存のスクラッチ抽出結果。前フェーズで座標抽出＋原本画像確認済みの
もの）から、以下の基準で40行を選定した。

- **基本36行**：12ヶ月それぞれから、甲子（各月1番目）・癸巳（各月30番目、
  月内中央付近）・癸亥（各月60番目・最終）の3行。二月丙寅・六月戊寅の
  原本欠落2行（前フェーズで原本画像確認済み）とは位置が重ならないため
  影響なし。
- **追加4行**：比較上有用な日として、宜が0件（俱不取）の日を2件
  （正月乙丑・八月丁卯）、宜が特に多い日を2件（十二月辛酉＝25件、
  五月丙申＝24件）を追加した。

選定データは`tests/fixtures/shogi_validation_samples.json`に保存した。

### 1.2 比較単位の構築

各サンプルの`rawText`（憲宜／協紀の原文）から、`docs/source/用事便覧.pdf`
基準ではなく擇日象意.pdf原文の語をそのまま`expectedKen`（憲宜側）・
`expectedXiejiAdditional`（協紀「加」側、`xiejiMode`が`add`/`xieji_only`の
場合のみ）・`expectedCombined`（`xiejiMode`に応じた統合。`same`→憲宜と
同一、`add`/`xieji_only`→憲宜＋協紀追加、`none`/`gap`→空）を構築した。

`xiejiMode`が`unknown`だった2行（前フェーズでOCR起因の構造曖昧と判定
済み）は、前フェーズの個別調査結果に基づき手動で補正した。

- 十月癸亥：`日【憲宜】【協紀】祭祀沐浴【協紀】仝` → 先頭の「【協紀】」は
  スプリアスな重複マーカーと判断し、`same`（憲宜＝祭祀・沐浴、協紀＝仝）
  として扱った（前フェーズ「用事語辞書・象意データの正規化」時の分析と
  同一の判断）。
- 六月甲子：`【協紀】`の直後に「加」が無いまま用事が並ぶ（本来「加」の
  文字がOCR/抽出時に欠落した可能性が高い）ため、`add`として扱った
  （協紀側の項目を憲宜への追加として統合）。

### 1.3 用事語の対応付け（原典表記差の扱い）

擇日象意.pdfの原文は繁体字・旧字体（例：入學・經絡・會親友・修飾垣墻・
豎柱上樑）を用いるが、`src/lib/takujitsu/activity/activityDefinitions.ts`
は主に擇日テキスト.pdf（現代日本語の講義資料）由来のためほとんどが
新字体（入学・経絡・會親友＝これは旧字体のまま採用済み・修飾垣墻＝
旧字体のまま採用済み）である。**未確認の類似語を勝手に同一視しない**
という方針のため、比較には以下の「既に確認済み」の対応のみを用いた
（`docs/takujitsu_activity_design.md` 3.2節で原本画像確認を経て既に
確定していた11ペア、および前フェーズで確定した2ペア）。

| 擇日象意.pdf側の表記 | ActivityDefinition側のid |
|---|---|
| 經絡 | 経絡 |
| 掃舍宇 | 掃舎宇 |
| 入學 | 入学 |
| 築隄防 | 築堤防 |
| 修置產室 | 修置産室 |
| 破屋壞垣 | 破屋壊垣 |
| 修飾垣墻 | 修飾垣墻（同一表記） |
| 會親友 | 會親友（同一表記） |

上記以外の一致しない語（豎柱上樑・納采問名・臨政親民・結婚姻・上表章・
求嗣・移徙・求醫療病・醞釀・捕捉・開倉庫出貨財・冠帶・畋獵など）は、
**「未確認」のため機械的に同一視せず**、`ActivityDefinition`に存在しない
語として別集計した（3.3節）。

### 1.4 実在日の割り当てと比較

擇日象意.pdfの各行は`monthBranch`×日干支の抽象表（実際の年月日を持たない）
のため、`CalendarEngine`が同じ`monthBranch`・`dayStem`・`dayBranch`を
返す実在日を2015年〜2034年の範囲で1件ずつ検索し（`tests/fixtures/gen_shogi_validation.ts`）、
その実在日で`calculateTakujitsu()` → `evaluateActivities()`を実行して
`positiveSources`を取得した。40サンプルすべてで実在日が見つかった。

**重要な限界**：この方法では、年干（歳徳等）・農暦月（天願・季分等）・
二十四節気（凶神第5グループ）・二十八宿の宿値日（伏斷日・埋兒凶宿・
二十八宿象意）に依存する神殺・暦注は、擇日象意.pdfの抽象表が本来
想定していない「たまたま選んだ年」の値で計算されてしまう。これらの
神殺・暦注がLOGIC_ONLYとして出た場合、必ずしも「ロジックの誤り」では
なく「検証方法上、年を固定したことによる付随的な差異」である可能性が
ある点に注意して結果を解釈する必要がある（15章で詳述）。

## 3. 差異の原因調査

### 3.1 単純な一致率だけでは見えないこと

一致率15.5%は低いが、内訳を見ると**LOGIC_ONLYの大半（643件中427件＝
66%）が吉神由来**であり、しかもそのうち擇日象意.pdf側に一度でも
現れた実績のある吉神は限られていた（下記3.2）。これは「ロジックが
壊れている」のではなく、**擇日象意.pdfの宜リストは実装済み69件の吉神
のうち一部（伝統的に核となる項目）だけを反映した表であり、日家吉神
すべてを機械的に合成した表ではない**ことを強く示唆する。

### 3.2 十二建除・二十八宿は擇日象意.pdfにほぼ含まれていない（16・17章の根拠）

- 十二建除由来のMATCHは4件のみ（LOGIC_ONLY 121件に対し一致率3.2%）。
  一致した4件はいずれも「除」（解除・沐浴等、汎用的な語のため他の
  出典と偶然重なった可能性が高い）。
- 二十八宿由来のMATCHは1件のみ（LOGIC_ONLY 95件に対し一致率1.1%）。
  一致した1件も「翼」の「出行」という汎用語。

十二建除・二十八宿がもし擇日象意.pdfの構成要素であれば、`建`＝伐木を
忌む・`除`＝解除等が宜、といった対応がもっと頻繁にMATCHするはずだが、
実際にはほぼ皆無だった。**したがって、擇日象意.pdf 720行の宜リストには
十二建除・二十八宿は含まれていない可能性が高い**、というのが今回の
サンプルからの結論である（720行全件照合で確認する必要はあるが、
40サンプルの一致率が偶然の水準（十二建除12種・二十八宿28種のいずれかが
たまたまその日の憲宜に含まれる語と一致する確率）を明確に下回っている
ことから、暫定的な結論として妥当性が高い）。

### 3.3 吉神は「一部の核となる項目」だけがMATCHしている

MATCHに寄与した吉神（延べ67件）の出典は次のとおりだった：

天徳・月恩・母倉・天願（季分・驛馬経由も含む）・三合・六合(直接は
未出現)・王日・官日・相日・民日・鳴吠・驛馬・吉期・時陰・天倉・神在・
福徳・福生・歳徳合・六儀

一方、LOGIC_ONLYにしか現れなかった吉神（例：青龍・明堂・金匱・寶光・
玉堂・司命・天瑞・天福・天貴・催官・兵吉・兵福・生氣・時陽・枝德・
天醫・天喜など）は、擇日テキスト.pdfの「日家吉神」棚卸しでは実装済み
だが、擇日象意.pdfの憲宜表には一度も採用されていなかった。

これは、擇日象意.pdf（＝『擇日天文學』という書籍の憲書・協紀辨方書
準拠の表）が、擇日テキスト.pdf（講義資料、日家吉神を網羅的に紹介）
よりも**狭い「伝統的に選定された吉神の核」だけを使って憲宜を編纂して
いる**ことを示す。擇日テキスト.pdfが69件の吉神を紹介しているのは
教育目的の網羅的なカタログであり、実際の通書編纂ではそのうち一部
（歳徳・天徳・月徳・天願・三合・六合・母倉・王官守相民日など）だけが
中心的に使われる、という擇日実務の慣行と整合する（`docs/takujitsu_decisions.md`
に記載の「陰陽不將の上吉／次吉」格付けが、まさにこの種の「吉神同士の
重み付け」という構造の存在を示唆している）。

### 3.4 SHOGI_ONLYの原因分類（A〜Iタクソノミー）

擇日象意側にはあるがロジック側に出なかった項目（SHOGI_ONLY、延べ188件
＋辞書非存在84件）を分類した。

| 原因分類 | 該当 | 延べ件数 | 判定根拠 |
|---|---|---|---|
| **F. 用事辞書の表記差** | 臨政親民・豎柱上樑・納采問名・結婚姻・上表章・求嗣・移徙・求醫療病・醞釀・捕捉・開倉庫出貨財・冠帶・畋獵（12語） | 84 | 擇日象意.pdfの繁体字・旧字体表記が現行辞書（擇日テキスト.pdf由来の新字体中心）に存在しない。未確認のため機械統合はしていない（1.3節） |
| **A/I. 該当する吉神・十二建除・二十八宿が現行データに一件も無い（源泉自体が無い）** | 修倉庫・修造動土・修飾垣墻・剃頭・安床・平治道塗・掃舎宇・整手足甲・栽種・立券交易・築堤防・納畜・経絡・裁衣・補垣塞穴・進人口（16語） | 94 | `ACTIVITY_PROFILES`を全数検索したが、これら16語を`favorableActivityIds`に含む吉神・十二建除・二十八宿プロファイルが1件も無い。`docs/takujitsu_activity_rules.md`を確認したところ、これらの語は**凶神の忌リストとしてのみ**登場し（例：修造動土＝月建・土王用事等の忌、裁衣＝土王用事の忌）、擇日テキスト.pdfのどの吉神・十二建除・二十八宿の説明にも宜として明記されていない。したがって単純な「抽出漏れ」（A）とは言い切れず、**擇日テキスト.pdfという原典自体が、これらの語を宜として明記していない**という原典の性質による可能性が高い（詳細は15章） |
| **G/I. 特定の吉神が成立したがその日は対象外だった（推定・通常の日差）** | 上官赴任・入学・出行・嫁娶・安碓磑・會親友・牧養・破土・破屋壊垣・祈福・祭祀・納財・解除・開市（16語） | 94 | これらはいずれも`ACTIVITY_PROFILES`上に対応する吉神・十二建除・二十八宿が存在するが、選んだサンプル日にその神殺が成立しなかった。40サンプルという限られた抽出のため、対応する神殺の成立日と重ならなかった可能性が高い（原因不明というより単純に日が違うため） |

### 3.5 LOGIC_ONLYの原因分類

| 原因分類 | 該当 | 延べ件数 |
|---|---|---|
| **D. 十二建除由来** | 3.2節参照 | 121 |
| **E. 二十八宿由来** | 3.2節参照 | 95 |
| **吉神由来（3.3節「核ではない吉神」）** | 3.3節参照 | 427 |
| **C. resolutionの影響／凶神由来の宜** | 月厭（祈福）・天乙絶気（安碓磑・作厠・埋坑） | 10 |

凶神由来のLOGIC_ONLY（10件）は、月厭・天乙絶気がサンプル日に成立し、
かつresolutionでcancelled/reducedになっていない（＝favorableがそのまま
反映された）ケースである。擇日象意.pdf側にこれらの語が無かったのは、
凶神起点の宜という特殊な構造自体が擇日象意.pdfの編纂方針に含まれて
いない可能性がある（件数が少なく、この40サンプルだけでは断定できない）。

## 4. 憲宜／協紀と現在のロジックの関係（18章）

MATCH50件のうち、47件が憲宜側、3件が協紀「加」側だった。この偏りは
サンプル数が少ないことに加え、協紀「加」が付く行自体が全720行のうち
一部（前フェーズの棚卸しでは「加」＋用事のパターンが観測されている）
であるため、単純な比率としては参考程度に留める。ただし**現状のロジックは
「憲宜」に近い項目を再現する傾向がある**（協紀由来の追加語は擇日テキスト.pdf
の吉神棚卸しにあまり反映されていない可能性がある）ことは言える。
720行全件照合を行えば、憲宜／協紀それぞれの再現率をより正確に算出できる。

## 5. 「月＋日干支 → 用事」への直接規則の有無（見出し「重要：月＋日干支のロジックを探す」）

今回のサンプル差異を踏まえ、擇日テキスト.pdf・12建除.pdf内に
「monthBranch＋dayGanzhi→用事」という**直接規則**が存在するかを
調査したが、**そのような規則を示す記述は見当たらなかった**。
擇日テキスト.pdfの構成は、神殺ごとに判定キー（月令・日辰・年干・農暦月等）
と象意を個別に記載する形式であり、「月＋日干支の組み合わせそのもの」を
キーとする表は存在しない（十二建除がmonthBranch＋dayBranchの組み合わせ
で決まる点は既存のとおりだが、これは「十二直」という別の体系であり、
擇日象意.pdfの憲宜そのものではない）。

したがって、**擇日象意.pdf 720行は、個々の神殺（主に吉神の一部）の
occurrenceを合成して作られた表である可能性が高く、月＋日干支に直接
紐づく別規則が擇日テキスト.pdf内に存在する証拠は見つからなかった**。
ただし、3.3節で述べた「吉神の核となるサブセット」が具体的にどの
組み合わせで選ばれているかは、擇日テキスト.pdf側からは明示的な
リストとして確認できていない（擇日テキスト.pdfが各吉神を個別紹介する
形式のため、「どの吉神が実務上の核か」という優先順位・選定基準自体は
本文に明記されていない）。この点は「I. 原典から原因を特定できない」
に該当する。

## 6. まとめ

1. **十二建除・二十八宿は擇日象意.pdfの憲宜表にほぼ含まれていない**
   （MATCH率1〜3%、いずれも汎用語の偶然の一致とみられる）。
2. **吉神は69件中一部の「核」だけが擇日象意.pdfの憲宜表に反映されている**
   （天徳・月恩・母倉・天願・王官守相民日・鳴吠・驛馬・吉期・時陰・
   天倉・神在・福徳・福生・歳徳合・六儀など）。残りの吉神（青龍系統・
   天瑞・天福・天貴・催官・兵吉・兵福・生氣・時陽・枝德・天醫・天喜等）
   は擇日テキスト.pdfには載っているが擇日象意.pdfの憲宜には反映されて
   いないとみられる。
3. **多数の「日常的な吉活動」（裁衣・立券交易・納畜・修倉庫・進人口・
   築堤防・経絡・整手足甲・掃舎宇・剃頭・栽種・補垣塞穴・安床・平治道塗・
   修造動土・修飾垣墻）は、擇日テキスト.pdfのどの吉神・十二建除・
   二十八宿にも宜として明記されておらず（凶神の忌としてのみ登場）、
   現行のロジックでは原理的に導出できない**。これは実装の抽出漏れ
   ではなく、擇日テキスト.pdf（講義資料）が擇日象意.pdf（通書準拠の
   完全な憲宜表）ほど網羅的に宜を記載していないという、原典の性質の
   違いによるものと考えられる。
4. **「月＋日干支→用事」の直接規則は擇日テキスト.pdf内に見当たらず**、
   擇日象意.pdfは個々の神殺のoccurrenceを合成した表である可能性が
   高いが、どの吉神が「核」として選ばれているかの選定基準自体は
   原典から特定できていない。

これらはいずれも**擇日象意.pdfの結果へ合わせるための逆算ではなく**、
`docs/takujitsu_activity_rules.md`の既存棚卸し結果（擇日テキスト.pdf
原典に基づく）を`ACTIVITY_PROFILES`全数検索することで確認した事実で
ある。既存ロジックの変更は一切行っていない。
