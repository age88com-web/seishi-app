- 出現資料／ページ／原文: `擇日テキスト.pdf` p.39、45)周堂殺・諸家周堂の忌リスト

  論評であり、「安香」という用事名の実在性を否定するものではない。
- 十二建除との関係: 直接の記載なし。
- 擇日実例・擇日象意720での出現: 確認できず（720はanswer-check資料であり不掲載は削除理由にしない）。
