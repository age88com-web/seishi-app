## 2. 凶神の対応確認（実装済みロスターとの突合）

洪氏錦嚢章に登場する神殺名のうち、本プロジェクトの実際のoccurrence実装
（`src/lib/takujitsu/shinsatsu/*.ts` の `kyojin.push(...)` 全66種）と**完全一致する文字列**
だけを対象とした。以下は方針として明示的に除外したもの（表記ゆれの可能性はあるが、
今回は推測で同一視していない）。

- 「大吏」→「天吏」への正規化のみ、本プロジェクトの他フェーズで既に確立している
  OCR誤記パターン（大/天の混同）として扱い、天吏として集計した。
- 「受死」（実装名は「受死日」）「四離絶」（実装名は「四離」「四絶」の2つに分離）
  「正四廢」（実装名は「四廢」）「上朔日」（実装名は「上朔」）「無禄日」（実装名は
  「無禄」）「地空凶日」（実装名は「地空」）「月殺凶日」（実装名は「月殺」）
  「八専日」（実装名は「八専」）「四忌日」（実装名は「四忌」）「伏断」（実装名は
  「伏斷日」）「炁往亡」（実装名は「氣往亡」）「天乙絶煞」（実装名は「天乙絶気」）
  「五離」（未実装、「四離」とは別語）「歳殺」（未実装、「災殺」とは別語）などは、
  **末尾の「日」「凶日」等の有無や字面の違いにより厳密には不一致**のため、今回は
  対応させていない（同一語である可能性を否定はしないが、断定する根拠が無いため）。
- 「白虎」「建星白虎」「虎中」「朱雀」「雀中」「天牢」「天刑」「天瘟」「土瘟」
  「地賊」「荒蕪」など、本プロジェクトの吉神・凶神ロスターに存在しない別体系の
  神殺名は、当然ながら未実装として除外した。

## 4. 今回のデータ設計に関する補足（未実装・参考情報）

- `conditionText`は「吉神にあうなど条件が合えば」「吉神があれば」「問題ない」
  「用いて良い」など、**原文の表現をそのまま保持**する想定（アプリ側で「解除済み」
  「使用可」等の断定はしない）。数量条件（「吉神が多ければ」、今回対象の8用事には
  出現しなかった）やraw/resolvedの区別が不明な場合も、条件文をそのまま表示すれば
  よく、機械判定は不要（`docs/takujitsu_hongshi_jishin_definition.md` §8参照）。
- 同じ `unfavorableGod` が同一用事内で複数のsourceTextを持つことは無かった
  （32件はすべて（用事,神殺）の組でユニーク）。
- マッチ条件は厳密に「(1) 用事がEXACT/ALIASで対応 かつ (2) 凶神が実装済みロスターと
  文字列完全一致」の場合のみとした。表記ゆれの可能性がある組み合わせ（§2）は
  今回いずれも対象外とし、将来ユーザーが個別に確認したうえで追加できるようにする。
- 表示は「その日に実際に成立している凶神」と一致した場合のみ（例：安床の日に
  実際に天賊または刀砧日が成立していなければ、安床の2件は表示されない）。この
  絞り込み自体は既存の`ActivityEvaluation.negativeSources`から`sourceName`を
  読むだけで判定でき、新しいoccurrence実装は不要と考えられる（未実装、参考情報）。
