# 目的

御定術数システムを、安全かつ段階的に開発するための実装計画。

既存の七政四餘を壊さず、
共通暦エンジンを構築し、
その後に奇門遁甲など他の術数へ展開する。

# 開発原則

既存の七政四餘が正常に動作している機能は変更しない。

新しい共通暦エンジンを独立して実装し、
十分な検証後に既存コードへ組み込む。

1080局は検証データとして使用する。
