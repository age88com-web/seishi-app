## 2. 原典の定義と用例

- 定義：神煞露 L1370「根源乃原守之辰，流星乃流歲之曜」。原守（出生時に守る星）に対し、流歳（流年）の曜。
- L1661「元守之星固好，又恐流年之星為患…經云：元守雖然無咎，尤恐流曜為殃」→ 流星＝流年之星＝流曜（元守／原守との対）。
- L1520「諸星在人盤不但原守為緊而流星及諸神殺，尤為緊關」→ 「諸星」の流星。特定の一星ではない。
- 対象の星（「流」を冠する用例）：火・金（太白）・計・太陰・氣・木・水・土・孛。羅は L1666「火羅亦到」。太陽の「流」用例は無い。
  → 七政＋四餘（十一曜）。年ごとに一星を選ぶ記述は無い。
- 位置の決め方（用例）：
  - L1147 張果自身の限：「限到亢金，昨晚流火剋金。太白今午…合退於辰」→ 判断時点（昨夜・今日午時）の実際の火星・金星の位置と順逆。
  - L1157「昨夜，客星犯金火」→ 天象の観測。
  - L1439 実例：「丙辰年壬辰月戊寅日，太陰值流，氣木在角度」→ 特定の日の流太陰・流紫気・流木星の宿。
  - L1161「天寶二載…流計加踏」→ その年の計都。
  - L1325「更看流年星殺之併沖，以斷某月何日之殞歿」、L1661「必候星出方好」、L1339「別過度之順逆…推入宮之先後」
    → 流星は年内で動き、入宮の先後・順逆・月日まで見る。
  - 張果星宗十二は十一曜それぞれの「算法」（L1529「置積日…」等）を載せ、任意の日の位置を求める方法を持つ。
  - 本命盤から進める・太歳宮から配当する・立春／誕生日の一点で固定する、という記述は無い。
- 基準日時：流星を「年の一点」で取る規定は無い。限の切替は L1663「大小二限以生日後交」（誕生日）だが、流星の年内の範囲（立春〜／誕生日〜／正月〜）は書かれていない。

| 語 | 判定 |

| 流星＝流歲之曜 | CONFIRMED（L1370） |
| 流曜＝流年之星 | CONFIRMED（L1661 の本文と経の引用が対） |
| 流年星辰 | ほぼ同義だが未確定。L1339「加流歲之星辰，次評流星」で別の手順として並び、L1667 では太歳十二神の直後に「流年星辰吉凶」とあり神殺を含む可能性がある |
| 歲曜 | 本文に無い |

## 4. 位置の精度（原典の用例から）

- 十二支宮：必要（「退於辰」「到命限」「入宮之先後」）。
- 宿：必要（「限到亢金…流火」「氣木在角度」「犯度」）。
- 度数：「三合者在三度內…對合者不過一度內」（L1631）は倒限（death_timing）だけ。通常ルールで度数の許容幅を定めた箇所は無い。
- 順逆：必要（L1339「別過度之順逆」、L1147「合退」）。
- 本命星との関係：必要なものがある（「流氣併當生之氣」「當生無難星…流年有難星」）。

## 5. 関係語

- 對合：L1631「對以衝照言、合以三方言」→ 對＝対宮、合＝三方（三合）。倒限の節の定義だが語の定義として明記。
- 到：「到命限」の到が宮に入ることか宿・度に及ぶことかは本文で定義されない（AMBIGUOUS）。
- 併：「流氣併當生之氣」の併（同宮か同宿か同度か）は未定義（AMBIGUOUS）。
- 逢・臨・會・照・沖・同躔：既存監査の扱いのまま（同躔＝同宿のみ確定、他は AMBIGUOUS）。

## 8. targetYear

- 現行：targetYear = birthYear + targetAge（0歳＝出生年）、流年干支は対象年の7月1日正午で引く。
- 原典：限は誕生日で交わる（L1663）。流星の年内範囲・年齢の数え方（数え年）は本文で規定されない。
- 流年干支・太歳・流年神殺は年単位の値なので現行のままで矛盾しない。流星は年内で動くため、targetYear だけでは一つの位置に決まらない。
