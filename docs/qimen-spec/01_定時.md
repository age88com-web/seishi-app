# 01. 定時

## 目的

用事を行う時刻を定めること。占う事象の発生時刻（占時）を四柱八字（年・月・日・時の干支）に変換し、そこから節気を確定する。式盤作成（作盤）の最初の段階。

## 講義資料での記載箇所

「式盤の作成（作盤）」のスライドに、定時・定局・演局の3段階のうちの1段階として、以下の1文のみが記載されていた。

> ①定時とは、用事を行う時刻を定める事。占時を四柱八字の干支に変換する。→節気を確定する。

これ以外に「定時」という章として独立に詳述しているスライドは、確認した67〜68枚の中には見つからなかった。

## 入力

- 用事を行う年月日時刻（占時）

## 出力

- 四柱八字（年干支・月干支・日干支・時干支）
- 節気

## 処理手順

講義資料の記載通りであれば、

1. 占う事象が発生した（または占う）年月日時刻を四柱八字の干支に変換する。
2. その日時が属する節気を確定する。

の2ステップのみである。干支・節気への具体的な変換方法（何を基準にするか、時刻の境界をどう扱うか等）についての記載は、確認した範囲のスライドには見つからなかった。

## 例

講義資料内に「定時」単体の計算例は見つからなかった。ただし「定局（局数）」の章の例題（[02_定局.md](./02_定局.md)参照）で、2015年9月8日午前10時という占時から、日干支（符頭経由）・節気（白露）が前提として使われている。

## 例外処理

講義資料内に記載なし。

## 実装時注意点

- このリポジトリでは、年月日時刻から干支・節気・ユリウス日等を求める処理はすでに `src/lib/calendar`（CalendarEngine）として七政四餘向けに実装済みであり、`docs/00_PROJECT.md` 系の方針でも奇門遁甲は共通暦エンジンの出力（`solarTerm` / `dayStem` / `dayBranch` / `hourStem` / `hourBranch` 等）を利用する前提になっている。講義資料の「定時」章はごく簡潔な記載に留まり、CalendarEngineの実装内容そのものを規定する記載ではない。
- 「不足している仕様」：定時の具体的な干支変換ロジック（子の刻の境界の扱いなど）は講義資料内に見当たらず、既存のCalendarEngineの挙動をそのまま踏襲する前提になっている。この点が講義資料で明示的に確認できていないことは明記しておく。
