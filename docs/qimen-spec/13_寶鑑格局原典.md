# 13. 『御定奇門寶鑑』格局原典データ（Phase 5B）

## 目的

『御定奇門寶鑑』の格局に関する記述を、格局の成立判定とは独立した原典解釈データとして保存する。
将来、宮で成立した現行格局（名称）や剋應（ID）から原典の記述を引けるようにする。
今回は巻一の3節（釋勃格飛伏・釋庚丙同刑異破・釋二吉四凶）を対象とする。

### 電子テキストとの主な異同

- 同刑異破: 電子テキストは「故曰格。丙所加者寅。寅與午三合。」13字を脱し、「相衝」を「相謀」とする（影印本を採る）。
- 「陰乾」は影印本「陰干」（自動変換誤りと確定）。「干逢克」は影印本「尅」。
- 「丙加巳為第四干」: 写本は己・已・巳を書き分けず、影印本でも未解消。
- 「庚為歲月日時干」「反首跌穴」: 影印本も同じ（疑義は未解消）。
- 歌訣注「直浮」→影印本「直符」、「仔細詳」→「仔細看」。凡例「回首」→「迴首」、圏点は「則為格勃勃格。又不可用。」。

### 『奇門法竅』卷二 (37)論庚丙格・(38)論龍鳥格（`FAQIAO_VIEWS`。『寶鑑』の規則にしない）

直符の庚×丙を龍返首、丙×直符の庚を鳥跌穴として成立させ、「然庚雖直符，不可以甲申所統之時蓋以凶論」「如甲丙相加又得吉門，誰云甲申旬之龍鳥吉格不堪取用乎」とし、三吉門・旺相なら用い、凶門は忌む。『寶鑑』凡例（用いない）とは逆の立場で、資料ごとに保持する。取得テキストは `docs/source/faqiao/`。
