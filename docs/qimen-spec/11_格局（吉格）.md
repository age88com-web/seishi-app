# 11. 格局（吉格）

## 目的

完成した排盤（各宮の 天盤干・地盤干・八門・八神）と、用事の時干支の六儀（旬首）・人盤値使門の宮から、該当する吉格を判定すること。

## 実装状況（2026-10-06 時点）

**実装済み。** `src/lib/qimen/jikaku.ts`。
- `resolveJikaku(input: JikakuInput)` … `{ palaces, liuyi, zhishiPalace, xunShou, hourGanzhi }` を受ける低レベルAPI。`palaces` は寄宮後の有効配置（外周8宮。`src/lib/qimen/effectivePalaces.ts`）。
- `resolveJikakuFromQimen(qimen: QimenResult)` … `qimenEngine.calculate()` の戻り値から直接判定するラッパ。`qimen.effectivePalaces` を渡す。`qimenEngine` はこれを呼んで戻り値 `jikaku` に格納する。
- 回帰テスト: `tests/qimen_jikaku.manual.ts`（1080.pdf の格局名ラベルと宮単位で照合）。

### 講義資料の誤読を修正した事項

- 旧仕様書は「格局詳細5＝五遁」で、天遁／地遁／人遁／神遁／鬼遁 が別条件で再登場するとしていた。**正しくは Slide-3905 は「五假」**（天假・地假・人假・神假・鬼假）。同名格の衝突は起きない。
- 旧仕様書の格名の判読誤り（人道→人遁、神盤→神遁、麒遁→龍遁、嵩貴→真詐、冨貴→重詐、謙貴→休詐 等）を修正。
- 旧仕様書で「玉女守門の干支リストは判読不整合（甲寅旬が2回・甲申旬欠落）」としていたのは**誤読**。撤回し、上の表（甲子〜甲寅の6旬）を旬条件として実装していたが、2026-10-06 の監修確定により旬条件は廃止した（下記）。
- 龍遁・虎遁の「または◯宮で同宮」の解釈をユーザー確定仕様で確定（B条件では地盤癸／地盤辛は不要。虎遁Bは休門のみ）。

### 監修確定事項（2026-10-06）：青龍返首の「天盤の旬首六儀」

- **青龍返首は、作盤上、時干の宮へ実際に転動された天盤干が旬首六儀となる場合に成立する。**
  - 天盤側: `tianpan.ts` の回転で各宮に置かれた天盤干（本来の天盤干）だけを見る。旬首六儀が中宮にある場合に、天禽とともに芮禽宮へ寄宮した中宮干は、青龍返首の「天盤の旬首六儀」としては扱わない。
  - 地盤側: 坤二宮の寄宮干（中宮から寄宮した地盤干）を含めて「地盤丙」を判定する。
- これは中宮寄宮の一般原則の例外ではなく、青龍返首の定義上の扱いである（1080.pdf の省略とは扱わない）。
  - 参考（講義 p22）: 六儀が中宮に来る場合は「坤に中宮の地盤干を寄せる。奇宮すると辛戊となるので、そのまま時干上に辛を置く」とあり、時干の上へ転動されるのは中宮の六儀そのものではない。
- 1080.pdf との照合（宮単位）: この条件で **一致120／判定のみ0／ラベルのみ0** の完全一致。
  - 寄宮後の干をそのまま天盤にも使うと、旬首六儀が中宮にある16件（No.43・93・143・191・193・196・243・533・581・583・589・633・683・733・783・1073）で判定のみが生じる。
  - 「時干の宮の転動天盤干」と「各宮の転動天盤干」のどちらで判定しても、成立宮は全局で同一（転動により旬首六儀は時干の宮に置かれるため）。
  - 地盤丙が坤二宮の寄宮干だけで満たされる成立は26宮あり、26宮とも 1080.pdf に青龍返首のラベルがある。
- 実装済み（`jikaku.ts` の青龍返首は `tianPanStems[0]`＝転動された天盤干で判定）。

### 1080.pdf との定義差（別問題として保留）

中宮寄宮を適用すると、1080.pdf に名称が無い吉格が新たに45件成立する（龍遁11・地假11・天假8・神假8・鬼假4・虎遁3）。虎遁の3件は、虎遁を休門のみとした監修確定により解消した（3件とも生門）。いずれも寄宮だけの問題ではなく、寄宮と無関係な不一致も同じ格に多数ある（龍遁45・虎遁13・天假50・地假136・神假79・鬼假49 ほか）。講義と 1080.pdf の吉格条件そのものの差として、別途扱う。

## 例外処理

複数の吉格が同時成立した場合の優先順位など、吉格判定固有の例外処理は講義スライドに記載が無い。
