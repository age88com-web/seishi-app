# 11. 格局（吉格）

## 目的

完成した排盤（各宮の 天盤干・地盤干・八門・八神）と、用事の時干支の六儀（旬首）・人盤値使門の宮から、該当する吉格を判定すること。

## 実装状況（2026-09-02 時点）

**実装済み。** `src/lib/qimen/jikaku.ts`。
- `resolveJikaku(input: JikakuInput)` … `{ palaces, liuyi, zhishiPalace, xunShou, hourGanzhi }` を受ける低レベルAPI。
- `resolveJikakuFromQimen(qimen: QimenResult)` … `qimenEngine.calculate()` の戻り値から直接判定するラッパ。`qimenEngine` はこれを呼んで戻り値 `jikaku` に格納する。

### 講義資料の誤読を修正した事項

- 旧仕様書は「格局詳細5＝五遁」で、天遁／地遁／人遁／神遁／鬼遁 が別条件で再登場するとしていた。**正しくは Slide-3905 は「五假」**（天假・地假・人假・神假・鬼假）。同名格の衝突は起きない。
- 旧仕様書の格名の判読誤り（人道→人遁、神盤→神遁、麒遁→龍遁、嵩貴→真詐、冨貴→重詐、謙貴→休詐 等）を修正。
- 旧仕様書で「玉女守門の干支リストは判読不整合（甲寅旬が2回・甲申旬欠落）」としていたのは**誤読**。撤回し、上の旬条件表（甲子〜甲寅の6旬）で確定・実装した。
- 龍遁・虎遁の「または◯宮で同宮」の解釈をユーザー確定仕様で確定（B条件では地盤癸／地盤辛は不要。虎遁Bは休門のみ）。

## 例外処理

複数の吉格が同時成立した場合の優先順位など、吉格判定固有の例外処理は講義スライドに記載が無い。

- **天盤寄宮干の廃止と天禽帯同干（2026-10-30 監修者の正式決定）**：地盤の寄宮干は天盤へ転記しない（旧 `tianPanLodged`・`tianPan[5]` は削除）。天禽・天芮に伴って運行する中五宮の干は、格局判定専用の独立データ `qinCompanion`（表示しない・剋應に使わない）として天盤干の判定候補に加える。以下の各 Phase の「芮禽同居宮の（天盤）寄宮干」はこの天禽帯同干を指し、成立条件は従来どおり。天禽帯同干でしか成立しない宮は `JikakuMatch.qinCompanionPalaces` で識別できる。
- **中五宮（2026-10-15 中宮寄宮 Phase 2）**：講義案N.pdf p.10「中五は無位で坤二に寄宮する」により、中五宮を独立した成立宮として返さない（`jikaku.ts` の `scan` が `stemAccess.ts` の `KAKU_SCAN_POLICY` で中五宮を除外）。吉格は従来も中五宮で成立した例が無く（1080局・4392時刻で0件）、判定結果は変わらない。寄宮干の格局判定への適用は下記 Phase 3D の6格局、Phase 3E の8格局、Phase 3F の9格局、Phase 3G の3格局（全吉格）。
- **寄宮干による三奇得使・三奇升殿の判定（2026-10-16 中宮寄宮 Phase 3D）**：乙奇得使・丙奇得使・丁奇得使・乙奇升殿・丙奇升殿・丁奇升殿に限り、寄宮干を含めて判定する（`jikaku.ts` の `pairScan`／`tianInPalace`、`stemAccess.ts` の `BASIC_PAIR_POLICY`）。成立条件・名称は変えない（値使・旬首六儀などの役割は参照しない）。
  - 天盤寄宮干は芮禽同居宮、地盤寄宮干は坤二宮で参照する。天盤寄宮干×地盤寄宮干は判定しない。中五宮は成立宮にしない。
  - 三奇升殿：1080.pdf の「乙奇昇殿・丙奇昇殿・丁奇昇殿」と局単位・宮単位で全1080局一致（135・136・135局）。
  - 三奇得使：寄宮で増えた宮はすべて 1080.pdf の「得使」ラベルの宮と一致するが、1080.pdf は逆向き（例: 天盤己・辛＋地盤乙）も「乙奇得使」と表記しており、講義案の一方向（天盤乙＋地盤己・辛）とは定義が異なる。逆向きも含めると 1080.pdf と一致するが、講義案の条件を優先し、逆向きは採用していない（ユーザー判断待ち）。
- **寄宮干による五遁・三詐の判定（2026-10-16 中宮寄宮 Phase 3E）**：天遁・地遁・人遁・神遁・鬼遁・真詐・重詐・休詐に限り、天盤干は芮禽同居宮の寄宮干も含めて判定する（`jikaku.ts` の `stemScanWithDi`／`stemScanTianOnly`、`BASIC_PAIR_POLICY`）。八門・八神・宮の条件、成立条件・名称は変えない（値符・旬首六儀などの役割は参照しない）。
  - 地盤干を条件に含む天遁・地遁だけ地盤寄宮干（坤二宮）も参照し、天盤寄宮干×地盤寄宮干は判定しない。人遁・神遁・鬼遁・三詐は地盤寄宮干を参照しない。中五宮は成立宮にしない。
  - 1080.pdf と局単位・宮単位で全1080局一致：天遁28・地遁19・人遁12・神遁20・眞詐167・重詐148・休詐154。
  - 鬼遁：寄宮で増えた2宮は 1080.pdf の「鬼遁」の宮と一致し、1080.pdf の鬼遁18宮はすべて成立する。ただし講義案の条件ではほかに28宮成立し、1080.pdf にはその鬼遁ラベルが無い（寄宮対応前からの差で、鬼遁の定義の違いによる。講義案の条件のまま）。
- **寄宮干による四遁・五假の判定（2026-10-16 中宮寄宮 Phase 3F）**：風遁・雲遁・龍遁・虎遁・天假・地假・人假・神假・鬼假に、Phase 3E と同じ判定（`stemScanWithDi`／`stemScanTianOnly`、`BASIC_PAIR_POLICY`）を適用。八門・八神・宮の条件、成立条件（龍遁・虎遁はユーザー確定の条件A・B）・名称は変えない。
  - 地盤干を条件に含む雲遁・龍遁・虎遁だけ地盤寄宮干（坤二宮）も参照する。風遁・五假は天盤干のみ。天盤寄宮干×地盤寄宮干は判定しない。中五宮は成立宮にしない。
  - 人假は寄宮対応しても成立が変わらない（天禽が壬を帯同する120局で、芮禽同居宮に驚門と九天が同時に入る局が無いため）。
  - 1080.pdf との照合：寄宮で増えた宮は、風遁・雲遁の全宮と、龍遁・虎遁の休門の宮が 1080.pdf のラベルの宮と一致する。1080.pdf の龍遁・虎遁は休門の宮にだけ付き（開門・生門の宮には寄宮の有無にかかわらず付かない）、風遁・雲遁も講義案の条件と成立宮が大きく異なる。いずれも寄宮対応前からの定義の違いで、講義案の条件のまま。1080.pdf は五假をほぼ表記しない（各1局のみ）ため、五假は講義案の条件から直接求めた結果と照合した。
- **寄宮干による青龍返首・飛鳥跌穴・玉女守門の判定（2026-10-16 中宮寄宮 Phase 3G）**：旬首六儀・値使を役割に使う3格局。`stemAccess.ts` の `XUNSHOU_ROLE_POLICY`（`roleUsesLodged` を天盤・地盤で区別：天盤＝使わない／地盤＝使う）と `jikaku.ts` の `roleScan` で判定する。成立条件・名称・玉女守門の旬条件は変えない。中五宮は成立宮にしない。天盤寄宮干×地盤寄宮干は判定しない。
  - 青龍返首（94→120宮）：天盤の旬首六儀は通常干のみ。天禽が帯同する寄宮干（旬首六儀が中五宮の盤）には旬首の役割を付けない（講義案 p.22・p.27 に天盤側の根拠が無く、1080.pdf も旬首六儀が中五宮の盤では青龍返首を付けない）。地盤丙は坤二宮の寄宮干も含む。1080.pdf と宮単位で120宮完全一致。
  - 飛鳥跌穴（96→130宮）：天盤丙は芮禽同居宮の寄宮干も含む。地盤の旬首六儀は坤二宮の寄宮干にも役割を認める（講義案 p.22 の坤二宮「辛(戊)」）。1080.pdf と宮単位で130宮完全一致。
  - 玉女守門（96→108宮）：値使門の宮は排盤結果のまま。その宮の地盤丁は坤二宮の寄宮干も含む。寄宮で増えた12宮はすべて 1080.pdf の「玉女守門」の宮と一致。1080.pdf は136宮で、差の28宮は旬条件の定義差（1080.pdf は旬ごとの時干支の条件を用いず、表に無い時干支にも玉女守門を付ける）。旬条件はユーザー確定仕様のまま維持。
