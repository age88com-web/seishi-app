# 11. 格局（吉格）

## 目的

完成した排盤（各宮の 天盤干・地盤干・八門・八神）と、用事の時干支の六儀（旬首）・人盤値使門の宮から、該当する吉格を判定すること。

## 実装状況（2026-09-02 時点）

**実装済み。** `src/lib/qimen/jikaku.ts`。
- `resolveJikaku(input: JikakuInput)` … `{ palaces, liuyi, zhishiPalace, xunShou, hourGanzhi }` を受ける低レベルAPI。
- `resolveJikakuFromQimen(qimen: QimenResult)` … `qimenEngine.calculate()` の戻り値から直接判定するラッパ。`qimenEngine` はこれを呼んで戻り値 `jikaku` に格納する。

### 講義資料の誤読を修正した事項

- 旧仕様書は「格局詳細5＝五遁」で、天遁／地遁／人遁／神遁／鬼遁 が別条件で再登場するとしていた。**正しくは Slide-3905 は「五假」**（天假・地假・人假・神假・鬼假）。同名格の衝突は起きない。
- 旧仕様書の格名の判読誤り（人道→人遁、神盤→神遁、麒遁→龍遁、嵩貴→真詐、冨貴→重詐、謙貴→休詐 等）を修正。
- 旧仕様書で「玉女守門の干支リストは判読不整合（甲寅旬が2回・甲申旬欠落）」としていたのは**誤読**。撤回し、上の旬条件表（甲子〜甲寅の6旬）で確定・実装した。
- 龍遁・虎遁の「または◯宮で同宮」の解釈をユーザー確定仕様で確定（B条件では地盤癸／地盤辛は不要。虎遁Bは休門のみ）。
