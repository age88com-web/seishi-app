# 10. 排盤完成

## 目的

地盤・天盤・九星・八門・八神をすべて重ね合わせ、九宮それぞれに全要素が配置された最終的な式盤（排盤）を完成させ、さらに格局（吉格・凶格）を判定すること。

## 実装状況（2026-09-02 時点）

**実装済み。** `src/lib/qimen/qimenEngine.ts` の `calculate(input: CalendarInput)`。公開窓口は `src/lib/qimen/index.ts`。

### 今回実装で確定した事項

- `calculate()` は CalendarEngine の結果を起点に、
  **定局 → 地盤 → 旬首 → 天盤 → 九星 → 八門 → 八神 → 格局（吉格・凶格）** を順に呼び出す薄い統合層。各排盤モジュールの内部ロジックは変更していない。
- 戻り値 `QimenResult` の主なフィールド：
  - `calendar` / `dingju` / `diPan` / `xunShou`
  - `tianPan` / `jiuXing` / `baMen` / `baShen`（各モジュールが例外を投げた場合は `null`、理由は対応する `*Error: string | null`）
  - `palaces: Record<1..9, PalaceSummary>` … 各宮の `{ diPanStem?, tianPanStem?, jiuXing[], baMen[], baShen[] }`
  - `jikaku: JikakuResult`（[11_格局（吉格）.md](./11_格局（吉格）.md)）
  - `kyokaku: KyokakuResult`（[12_格局（凶格）.md](./12_格局（凶格）.md)）
- **未算出の段の扱い**：あるモジュールが例外を投げた場合、その段だけ `null`／空にして統合処理は止めない。格局側は必要な段（天盤・八門・八神など）が欠けている格をスキップし、`jikaku.unavailable` / `kyokaku.unavailable` に段名を返す。
- 格局判定は、排盤まで組み立てた `QimenResult` を `resolveJikakuFromQimen()` / `resolveKyokakuFromQimen()` に渡して得る。両ラッパは `palaces` / `xunShou` / `baMen` / `baShen` / `jiuXing` / `calendar` / `dingju` のみ参照する読み取り専用関数。

### 講義資料の誤読を修正した事項（訂正履歴）

- 当初、元Keynote のスライドサムネイル（低解像度）から本章を作成した際に参照した「排盤の完成」図は、**八門の配置が正しい定位の対宮（環の反対側）に8宮すべてずれて記載**されていた。ユーザー提供の正しい完成盤資料（`奇門遁甲講義案配盤完成.pdf`）で再確認した結果、旧図に誤りがあり、正しい完成盤では `bamen.ts` の導出結果と一致した（[08_八門.md](./08_八門.md)参照）。
- 完成盤資料の各マスの2段目の干は**天盤ではなく、六儀三奇↔九星の固定対応を示す参考ラベル**（戊↔天蓬・己↔天芮・庚↔天沖・辛↔天輔・壬↔天禽・癸↔天心・丁↔天柱・丙↔天任・乙↔天英）。局・時刻によらず変化しない。天盤は完成盤資料には載らない（[06_天盤.md](./06_天盤.md)で別途確認）。

### この例の格局判定結果

- **吉格**：鬼遁＠8（杜門＋天盤丁＋九地）／丙奇升殿＠9（天盤丙が離九宮）／地假＠8（杜門＋天盤丁＋九地）。

- いずれも各スライド本文の条件に逐一照合済み（[11](./11_格局（吉格）.md)・[12](./12_格局（凶格）.md)参照）。`unavailable` は吉格・凶格とも空。

## 例外処理

排盤完成の段階に固有の例外処理は講義資料に無い（各要素の例外は04〜09、格局の例外は11〜12で扱う）。
