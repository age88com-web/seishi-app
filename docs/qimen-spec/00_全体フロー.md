# 00. 全体フロー

## 出典についての注記

本仕様書群は、講義資料「奇門遁甲講義案N」（Keynoteファイル、以下「講義資料」）の全スライドを読み、記載されている内容のみを転記・整理したものである。講義資料以外の一般的な奇門遁甲理論は一切追加していない。

講義資料はKeynote形式（.key）であり、直接のテキスト抽出ができなかったため、パッケージ内に保存されている各スライドのサムネイル画像（267×200px、67〜68枚）を1枚ずつ目視で読み取って書き起こした。解像度の制約により、一部の細かい文字・小さな表の数値は判読困難であった。判読できなかった箇所は各章のファイル内に「判読困難」として明記している。

また、スライドの並び順（内部ファイル名の番号）を手掛かりにしたが、内容を確認したところ番号順と実際のスライド順が必ずしも一致していないことが分かった（例：番号49〜89のスライドは「基本象意」という九星・八門・八神の意味の一覧表だが、内容的には後続の章に対応する解説と考えられる）。そのため本仕様書群は、スライドの物理的な並び順ではなく、**内容が対応する章ごとに再構成**してある。

## 講義資料に記載されていた三式・奇門四家（背景知識）

- **三式**：天式＝天時を得る術＝太乙神数、地式＝地利を得る術＝奇門遁甲、人式＝人和を得る術＝六壬神課。すべて「卜」に属するが、占卜だけでなく命術としても信憑性が高い術である。
- **奇門遁甲とは**：諸葛孔明が用いて戦勝したとされる方位学。伝説では黄帝が蚩尤と戦った時に、天帝から与えられたとされる。宋代の避難令「懺悔安要」とも言われる。占うにはそれに行動しがちだというわけではないが、即効性が求められる占いをする際、戦局を突きあるいは占いをする際に用いられた術と一様に伝えられている。三式の中でも比較的一般の人の目に触れる機会が少なく、一般に知られる術ではない。
- **奇門遁甲という名称の由来**：周・秦の代に「陰遁」とよばれ、漢代・晋代で「六甲」、晋・宋代でようやく「奇門遁甲」と呼ばれるようになった。奇門とは、甲を九干にわけた「奇」が、十干のなかの乙、丙、丁の三奇を指す。三奇の逃げ方位を求める。「門」とは、八門のことをいう。三奇と八門を用いるための門である。「遁甲」とは、十干の最も貴い甲干が、庚に見立てるのを恐れ、隠遁することを忌み、甲干を隠すこと、すなわち甲干を隠して他の干にすることをその術のなかに含んでいることから意味する。
- **奇門遁甲の系譜**：①法奇門（法術奇門）＝道教と奇門遁甲が結びついたもの。符術などを用いたりする、なり神秘的な術として発展している。しかし、あまり一般的ではない。②数理奇門＝数理を用いて式盤を作成し、未来を占う。天盤、地盤、人盤、神盤という四つの位置と九六儀六格それぞれの関係性を読み解き、様々な未来予測を可能にしている。
- **奇門四家**：年家奇門＝年単位で予測を行う。国家存亡の一大事に用いられる。作用期間は60年といわれている。月家奇門＝一ヶ月以内に起こる事象の予測に用いられる。隆盤の使用も60ヶ月。日家奇門＝一日の内に起こる事象の予測に用いられる。金函玉鏡と作用期間は60日。時家奇門＝時（二時間）における予測に用いられる。最も精度がある使用頻度も高く、広い範囲の予測に使用可能。作用期間60時間。

## 式盤の構成要素（講義資料の整理）

式盤は以下の要素から構成される。

- 陰陽五行
- 易経八卦
- 天干地支
- 星相術

内訳（構成要素②〜⑤として記載）：

1. **三奇六儀**：甲を除いた十干（甲は旬首に隠れている：後述）。三奇＝乙儀・丙儀・丁儀。六儀＝戊儀・己儀・庚儀・辛儀・壬儀・癸儀。
2. **八門**：休門（きゅうもん）・生門（しょうもん）・傷門（しょうもん）・杜門（ともん）・景門（けいもん）・死門（しもん）・驚門（きょうもん）・開門（かいもん）。
3. **九星**：天蓬（てんぽう）・天芮（てんげい）・天沖（てんちゅう）・天輔（てんほ）・天禽（てんきん）・天心（てんしん）・天柱（てんちゅう）・天任（てんにん）・天英（てんえい）。
4. **八神**：別名「八将門」。直符（ちょくふ）・騰蛇（とうだ）・太陰（たいいん）・六合（りくごう）・勾陳（こうちん）・朱雀（すざく）・九地（きゅうち）・九天（きゅうてん）。
5. **九宮八卦**：中五は無位で坤二に寄宮する（洛書九宮）。

洛書九宮（後天数）：

## 式盤の作成（作盤）の全体フロー

講義資料には次の3段階が明記されている。

**定時 → 定局 → 演局**

1. **定時**：用事を行う時刻を定める事。占時を四柱八字の干支に変換する。→節気を確定する。（詳細は [01_定時.md](./01_定時.md)）
2. **定局**：陰遁か陽遁かを定める事。節気から定まる（陽遁・陰遁が決まれば局数も決まる。日付と時刻のみで決まる）。
   - 陽遁以降（冬至〜小満）：冬至、小寒、大寒、立春、雨水、啓蟄、春分、清明、穀雨、立夏、小満、芒種
   - 陰遁以降（夏至〜大雪）：夏至、小暑、大暑、立秋、処暑、白露、秋分、寒露、霜降、立冬、小雪、大雪
   （詳細は [02_定局.md](./02_定局.md)、超神接気・置閏の補正は [03_超神接気・置閏.md](./03_超神接気・置閏.md)）
3. **演局**：地盤→旬首→天盤→九星→八門→八神の順に式盤を組み立てていく段階（本仕様書群では04〜09に相当）。

## 本仕様書群の対象外の内容

講義資料には、排盤の完成後に格局を用いて実際の吉凶判断・行動指針を導く「用事別の造作法」（求財・求婚・訴訟・試験・病気治療・家内安全など、格局をどう活用するかの実践的ガイド）が多数収録されていた。これは排盤（式盤の作成）そのものの仕様ではなく、完成した式盤を使った鑑定の応用知識であるため、今回依頼された12ファイルの対象範囲外と判断し、本仕様書群には含めていない。必要であれば別途「13_用事別造作法.md」等として整理することも可能だが、今回の指示範囲を超えるため着手していない。

## 不足・不明点の総括

- 講義資料のスライド順が内部ファイル番号と一致しない箇所があり、完全な「ページ順」の再現はできていない（内容ベースで再構成した）。
- 一部のスライド（超神接気の置閏の具体例、格局詳細の一部）は解像度の制約で数字・細かい漢字が判読困難だった。各該当ファイルに個別に明記している。
- 「地盤」の六儀三奇の配列方向について、講義資料の**文章記述**（六儀と三奇で飛泊方向が逆になる）と、講義資料の**具体例図**（陽遁一局：1戊2己3庚4辛5壬6癸7丁8丙9乙、単純に同一方向で並ぶ）に食い違いがある。既存実装 `dipan.ts` はユーザーの指示によりすでに具体例図を優先する形で確定しているが、文章記述との矛盾がある事実は [04_地盤.md](./04_地盤.md) に明記した。
