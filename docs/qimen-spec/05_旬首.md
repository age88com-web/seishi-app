# 05. 旬首

## 目的

時干支から、その時刻が属する旬・旬首・六甲の隠れている六儀（liuyi）を求めること。

## 実装状況（2026-09-02 時点）

**実装済み。** `src/lib/qimen/xunshou.ts` の `resolveXunShou({ hourStem, hourBranch })`。

### 今回実装で確定した事項

- 旬首の求め方：時干支の60干支インデックス `hourIndex` から `hourIndex - (hourIndex % 10)` を旬の先頭インデックスとし、その干支（`甲＋支`）を旬首とする。旬名は「旬首＋旬」（例: `甲子旬`）。
- 旬首の支 → 六儀（liuyi）の対応表（`LIUYI_TABLE`、ユーザー確認済み）：

  | 旬 | 旬首 | liuyi |
  |---|---|---|
  | 甲子旬 | 甲子 | 戊 |
  | 甲戌旬 | 甲戌 | 己 |
  | 甲申旬 | 甲申 | 庚 |
  | 甲午旬 | 甲午 | 辛 |
  | 甲辰旬 | 甲辰 | 壬 |
  | 甲寅旬 | 甲寅 | 癸 |

- 対応表に無い支のときは例外（実際には旬首は必ず上記6つのいずれか）。
- **判定に使うのは時干支**（日干支ではない）。
- 戻り値 `{ xun, xunShou, liuyi }`。`xunShou`（旬首の干支文字列）は八門の値使計算で、`liuyi` は天盤・九星・八門で使う。
- **確定例**：辛卯時 → `hourIndex=27` → 旬先頭 `20` = 甲申 → 旬首 `甲申`・liuyi `庚`（`10_排盤完成.md` の陽一局例と整合）。

## 講義資料での記載箇所

「天盤干の配列」スライド冒頭部分。

> 天盤を配列するには、旬首を見つける。
> 六十甲子には六つの旬がある。その旬の最初に来る干支を旬首という。
> 旬首が求まったら、次に旬首と同じ地盤の干支の位置（六儀）を寄せる。
> その六儀を起点に、地盤に配置した同じ配列で配列する。

## 例

「天盤干の配列」スライドの例題（2015年9月8日午前10時＝時干支 乙巳）→ 旬 甲辰旬・旬首 甲辰・liuyi 壬。スライド記載の「六儀：壬」と一致。

## 追加資料による正式根拠（2026-10-06）

出典: 追加資料（時盤作盤の手順。ユーザー提示 2026-10-06、`docs/source/` 未収録）

時盤作盤の手順「時干支から旬首を求める → 旬首の甲を六儀に隠す」の根拠。

> 旬首となる時干支、つまり時干が甲となる場合は六儀に隠れています

> （庚午時の旬首は甲子）甲子は戊のもとに隠蔵されているため、六儀は戊

- 時干が甲のときは、甲そのものではなく、時干支の旬首に対応する六儀として扱う。現在の実装（`xunshou.ts` の旬首→六儀、`tianpan.ts`・`jiuxing.ts` の甲時の扱い、`kyokaku.ts` の `concealJiaHourStem`）を正式仕様とする。
- 資料の例「庚午時 → 旬首 甲子 → 六儀 戊」は `resolveXunShou({ hourStem: "庚", hourBranch: "午" })` の結果（甲子旬・旬首 甲子・六儀 戊）と一致する。
- 年干・月干が甲の場合の扱いは、本資料が時盤作盤（時干支）を対象とするため根拠にならない。現段階では保留（歳格・月格は年干・月干をそのまま使う）。
