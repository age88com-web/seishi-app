# 12. 格局（凶格）

## 目的

完成した排盤（各宮の 天盤干・地盤干・八門・八神・九星）と、年干・月干・日干・時干支・陰陽遁・値符の宮から、該当する凶格を判定すること。

## 実装状況（2026-09-02 時点）

**実装済み。** `src/lib/qimen/kyokaku.ts`（`jikaku.ts` とは別ファイル）。
- `resolveKyokaku(input: KyokakuInput)` … `{ palaces, dun, yearStem, monthStem, dayStem, hourStem, hourGanzhi, zhifuPalace }`。
- `resolveKyokakuFromQimen(qimen: QimenResult)` … ラッパ。`qimenEngine` が呼んで戻り値 `kyokaku` に格納する。値符の宮は 九星値符 を優先、無ければ 八神直符（通常同一宮）。

### 別ファイルにした理由

凶格は入力集合が吉格と異なる（歳/月/日/時格・悖格＝年月日時干、伏吟/反吟格＝陰陽遁と定位、伏宮/飛宮/符勃/飛悖格＝値符の宮）。`JikakuInput` に混ぜると別物になり、確定済みの `jikaku.ts` を触る必要が出るため分離した。

**五不遇時 表**（日干→用事の時干支）：甲→庚午／乙→辛巳／丙→壬辰／丁→癸卯／戊→甲寅／己→乙丑／庚→丙子／辛→丁酉／壬→戊申／癸→己未

**時干入墓 表**（時干支→天盤干／宮）：丙戌→丙/乾6／壬辰→壬/巽4／癸未→癸/坤2／戊戌→戊/乾6／己丑→己/艮8／丁丑→丁/艮8

**伏吟格の3種**（該当する下位分類だけ detail に出す）：
- 九星伏吟：外周8宮すべてが定位星（needs 九星）
- 値符伏吟：八神「直符」が定位（陽遁＝坎1／陰遁＝離9）にある（needs 八神）
- 八門伏吟：外周8宮すべてが定位門（needs 八門）

**反吟格の3種**：上記の「定位」を「定位の相沖宮」に置き換えたもの。

**門迫**：休門→{坤2, 艮8}／生門→{震3, 巽4}／死門→{震3, 巽4}／景門→{坎1}／開門→{離9}／驚門→{離9}／傷門→{乾6, 兌7}／杜門→{乾6, 兌7}
**宮迫**：休門→{離9}／死門→{坎1}／傷門→{坤2, 艮8}／杜門→{坤2, 艮8}／開門→{震3, 巽4}／驚門→{震3, 巽4}／景門→{乾6, 兌7}

出力：`{ matches: [{ name, palaces[], detail?, meaning, source }], unavailable: Segment[] }`。
`Segment` ＝ `天盤` / `八門` / `八神` / `九星` / `値符`。盤全体格（伏吟格・反吟格・五不遇時）は `palaces: []`。

### 講義資料の誤読を修正した事項（旧仕様書 → 実装）

- **大格**：旧「天盤庚が地盤癸」→ 本文どおり **「天盤庚が地盤丙」**（太白入熒と同条件）。
- **乙/丙/丁奇入墓・三奇受刑の宮**：旧「艮六宮」→ 本文どおり **乾六宮(6)／坤二宮(2)／艮八宮(8)**。
- **五不遇時の表**：旧の判読不能な表 → 本文の10組で確定（上表）。
- **時干入墓の表**：旧「丙戌→艮宮、庚未→坤宮…」等 → 本文の6組（丙戌/壬辰/癸未/戊戌/己丑/丁丑）で確定。
- **符勃格**：旧「天盤丙が地盤壬」→ 本文どおり **「天盤丙が地盤値符と同宮」**（値符の宮の天盤干が丙）。飛悖格も同様に「値符の宮の地盤干が丙」。
- **六儀撃刑**：旧「判読困難」→ 戊/己/庚/辛/壬/癸 → 震3/坤2/艮8/離9/巽4/巽4 で確定。
- **伏宮格天乙格／飛宮格天乙太白**：「地盤の値符に臨む」＝値符の宮を指すと解釈し、値符の宮の天盤干／地盤干が庚かで判定。
- **門迫／宮迫**：五行の再導出はせず、本文の門→宮の列挙をそのまま表化。

## 例外処理

複数の凶格が同時成立した場合の優先順位、吉格と凶格が同時成立した場合の扱いは講義スライドに記載が無い。
