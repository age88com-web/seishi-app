# 12. 格局（凶格）

## 目的

完成した排盤（各宮の 天盤干・地盤干・八門・八神・九星）と、年干・月干・日干・時干支・陰陽遁・値符の宮から、該当する凶格を判定すること。

## 実装状況（2026-10-06 時点）

**実装済み。** `src/lib/qimen/kyokaku.ts`（`jikaku.ts` とは別ファイル）。
- `resolveKyokaku(input: KyokakuInput)` … `{ palaces, dun, yearStem, monthStem, dayStem, hourStem, effectiveDayStem, effectiveHourStem, hourGanzhi, zhifuPalace }`。`palaces` は寄宮後の有効配置（外周8宮。`src/lib/qimen/effectivePalaces.ts`）。
- `resolveKyokakuFromQimen(qimen: QimenResult)` … ラッパ。`qimenEngine` が呼んで戻り値 `kyokaku` に格納する。`qimen.effectivePalaces` と遁甲変換後の日干・時干を渡す。値符の宮は 九星値符 を優先、無ければ 八神直符（通常同一宮）。

### 中宮の寄宮と遁甲（監修原則 2026-10-06）

**中宮の寄宮**
- 地盤は六儀三奇を割り出すための基礎配列であり、地盤原盤では中宮5に干を置く（`dipan.ts`・`QimenResult.palaces` は変更しない）。
- 中宮には方位が無い。天盤以降・格局判定では中宮5を独立した宮として扱わず、中宮要素を寄宮先へ移す（天禽が天芮と同宮するのも同じ原則）。
  - 中宮の地盤干 → **坤二宮の寄宮干**（講義 p10「中五は無位で坤二に奇宮する」、p22）
  - 中宮由来の天盤干（天禽が帯同する干） → **芮禽宮の天盤干**（講義 p24）
- その結果、坤二宮は「本来の地盤干＋中宮から寄宮した地盤干」、芮禽宮は「本来の天盤干＋中宮由来の天盤干」を持つ。これを `QimenResult.effectivePalaces`（外周8宮）として排盤データとは別レイヤーで持つ。
- 凶格は外周8宮のみで判定し、干の条件は「その宮の天盤干（地盤干）のいずれかが該当する」で判定する。直符伏吟／反吟は寄宮干を含めた干の集合で比較する。
- 有効配置の天盤は 1080.pdf の天盤表示（中宮由来の干を芮禽宮に描く）と 1080/1080 一致する。
- UI の地盤表示は中五の干をそのまま残す（天盤表示での第二天盤干の扱いは将来整理）。

**遁甲（甲を表に出さず六儀に隠す）**
- 時干が甲 → その時干支の旬首に対応する六儀として判定（時格・時悖格・天網四張・地網遮蔽）。
- 日干が甲 → 戊として判定（日格・日悖格・伏干格・飛干格）。
- 年干・月干が甲の場合（歳格・月格・年悖格・月悖格）は講義資料上の扱いを確認中のため変換しない。
- 五不遇時・時干入墓は時干支（日干）の対応表なので、変換前の干支で引く。

**1080.pdf との既知の差（61件）**
- 坤二宮の寄宮干が（遁甲変換後の）時干・日干と同じ局で、本実装は時格（23件）・伏干格＝日格（32件）・時悖格（6件、1080.pdf の「時勃」）を判定するが、1080.pdf の該当宮にラベルが無い。
- 寄宮原則を優先し、時格・日格だけ寄宮干を無視する例外は設けない。1080.pdf と本実装のどちらが誤りとも断定せず、**寄宮原則による本実装と 1080.pdf との既知の差** として `tests/qimen_kyokaku.manual.ts` の `KNOWN_DIFFS` に固定する。
- それ以外の、干の組合せで決まる9格・六儀撃刑・飛干格は 1080.pdf と宮単位で完全一致する。

### 別ファイルにした理由

凶格は入力集合が吉格と異なる（歳/月/日/時格・悖格＝年月日時干、伏吟/反吟格＝陰陽遁と定位、伏宮/飛宮/符勃/飛悖格＝値符の宮）。`JikakuInput` に混ぜると別物になり、確定済みの `jikaku.ts` を触る必要が出るため分離した。

### 講義資料の誤読を修正した事項（旧仕様書 → 実装）

- **大格**：旧仕様書「天盤庚が地盤癸」→ 一時「天盤庚が地盤丙」（講義本文どおり）に変更 → **監修確定で「天盤庚が地盤癸」**（講義本文が誤記）。
- **乙/丙/丁奇入墓・三奇受刑の宮**：旧「艮六宮」→ 本文どおり **乾六宮(6)／坤二宮(2)／艮八宮(8)**。
- **五不遇時の表**：旧の判読不能な表 → 本文の10組で確定（上表）。
- **時干入墓の表**：旧「丙戌→艮宮、庚未→坤宮…」等 → 本文の6組（丙戌/壬辰/癸未/戊戌/己丑/丁丑）で確定。
- **符勃格**：旧「天盤丙が地盤壬」→ 本文どおり **「天盤丙が地盤値符と同宮」**（値符の宮の天盤干が丙）。飛悖格も同様に「値符の宮の地盤干が丙」。
- **六儀撃刑**：旧「判読困難」→ 戊/己/庚/辛/壬/癸 → 震3/坤2/艮8/離9/巽4/巽4 で確定。
- **伏宮格天乙格／飛宮格天乙太白**：「地盤の値符に臨む」＝値符の宮を指すと解釈し、値符の宮の天盤干／地盤干が庚かで判定。
- **門迫／宮迫**：五行の再導出はせず、本文の門→宮の列挙をそのまま表化。

## 例外処理

複数の凶格が同時成立した場合の優先順位、吉格と凶格が同時成立した場合の扱いは講義スライドに記載が無い。
