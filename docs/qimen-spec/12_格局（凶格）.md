# 12. 格局（凶格）

## 目的

完成した排盤（各宮の 天盤干・地盤干・八門・八神・九星）と、年干・月干・日干・時干支・陰陽遁・値符の宮から、該当する凶格を判定すること。

## 実装状況（2026-09-02 時点）

**実装済み。** `src/lib/qimen/kyokaku.ts`（`jikaku.ts` とは別ファイル）。
- `resolveKyokaku(input: KyokakuInput)` … `{ palaces, dun, yearStem, monthStem, dayStem, hourStem, hourGanzhi, zhifuPalace }`。
- `resolveKyokakuFromQimen(qimen: QimenResult)` … ラッパ。`qimenEngine` が呼んで戻り値 `kyokaku` に格納する。値符の宮は 九星値符 を優先、無ければ 八神直符（通常同一宮）。

### 別ファイルにした理由

凶格は入力集合が吉格と異なる（歳/月/日/時格・悖格＝年月日時干、伏吟/反吟格＝陰陽遁と定位、伏宮/飛宮/符勃/飛悖格＝値符の宮）。`JikakuInput` に混ぜると別物になり、確定済みの `jikaku.ts` を触る必要が出るため分離した。

### 講義資料の誤読を修正した事項（旧仕様書 → 実装）

- **大格**：旧「天盤庚が地盤癸」→ 一時、講義案Nの本文どおり「天盤庚が地盤丙」（太白入熒と同条件）としたが、Phase 3J-2（2026-10-16）で **「天盤庚が地盤癸」** に戻した。講義案Nの「地盤丙」は訂正対象（下記 Phase 3J-2）。
- **乙/丙/丁奇入墓・三奇受刑の宮**：旧「艮六宮」→ 本文どおり **乾六宮(6)／坤二宮(2)／艮八宮(8)**。
- **五不遇時の表**：旧の判読不能な表 → 本文の10組で確定（上表）。
- **時干入墓の表**：旧「丙戌→艮宮、庚未→坤宮…」等 → 本文の6組（丙戌/壬辰/癸未/戊戌/己丑/丁丑）で確定。
- **符勃格**：旧「天盤丙が地盤壬」→ 本文どおり **「天盤丙が地盤値符と同宮」**（値符の宮の天盤干が丙）。飛悖格も同様に「値符の宮の地盤干が丙」。
- **六儀撃刑**：旧「判読困難」→ 戊/己/庚/辛/壬/癸 → 震3/坤2/艮8/離9/巽4/巽4 で確定。
- **伏宮格天乙格／飛宮格天乙太白**：当初は「値符の宮」と解釈し、値符の宮の天盤干／地盤干が庚かで判定していた。Phase 3J-2（2026-10-16）で、地盤の値符＝地盤の旬首六儀、天盤の値符＝天盤の旬首六儀に改めた（下記 Phase 3J-2）。
- **門迫／宮迫**：五行の再導出はせず、本文の門→宮の列挙をそのまま表化。

## 例外処理

複数の凶格が同時成立した場合の優先順位、吉格と凶格が同時成立した場合の扱いは講義スライドに記載が無い。

- **天盤寄宮干の廃止と天禽帯同干（2026-10-30 監修者の正式決定）**：地盤の中五宮干は地盤（坤二宮）にのみ寄宮し、天盤へ転記しない。旧 `tianPanLodged` と天盤の中宮干（旧 `tianPan[5]`）は削除した。一方、天禽・天芮に伴って運行する中五宮の干は「盤面には表示しないが、格局判定では使用する」と決定されたため、格局判定専用の独立データ `qinCompanion`（`stemAccess.ts` の `QinCompanionStem`。値＝中五宮の地盤干、宮＝天禽・天芮の宮）として持つ。以下の各 Phase に書かれた「芮禽宮（芮禽同居宮）の天盤寄宮干」は、この天禽帯同干を指す（成立条件・自己組み合わせの例外・`FUGONG_POLICY` は従来どおり）。天禽帯同干でしか成立しない宮は `KyokakuMatch.qinCompanionPalaces` で識別できる。九宮盤・宮詳細・検索候補・比較・印刷には表示せず、剋應にも使わない。1080.pdf の格局ラベル・凶格例.pdf 190〜193頁の時悖格・符勃格の例と一致する。
- **中五宮（2026-10-15 中宮寄宮 Phase 2）**：講義案N.pdf p.10「中五は無位で坤二に寄宮する」により、中五宮を独立した成立宮として返さない（`kyokaku.ts` の `scan` が `stemAccess.ts` の `KAKU_SCAN_POLICY` で中五宮を除外）。中五宮の天盤干＝地盤干（回転しない）であるため、従来は戦格・歳格・月格・日格・時格・年悖格・月悖格・日悖格・時悖格・伏干格・飛干格・天網四張・地網遮蔽が中五宮だけで成立していた。中五宮の干のデータ、坤二宮・芮禽同居宮の寄宮干（`diPanLodged`／`tianPanLodged`）と盤面表示は維持。寄宮干の格局判定への適用は下記 Phase 3A の6格局、Phase 3B の刑格、Phase 3C の上格・奇格・戦格、Phase 3I の乙奇入墓・丙奇入墓・丁奇入墓・三奇受刑・六儀撃刑、Phase 3J-2 の大格・伏宮格天乙格・飛宮格天乙太白、Phase 3L の符勃格・飛悖格、Phase 4C の年悖格・月悖格・日悖格・時悖格のみ。盤全体の格（伏吟格・反吟格・五不遇時）と、値符・値使・固定宮で判定する格は中五宮を返さないため影響なし。
