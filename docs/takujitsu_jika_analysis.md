## 1. 表全体の構造

### 1.1 ページ構成

全11ページのうち、**1〜10ページが60日干支の個票（局）、11ページ目が凡例
（時家吉神析義・時家凶神註解・十二時辰表）**であることを確認した。

各ページは見開き2面（1画像に2ページ分）で構成され、1面に3行×2列＝6局が
配置されている。各局のタイトルは「局時日◯◯」という形式（例：「局時日午甲」）で、
右から左に読むと「甲午　日　時　局」＝**日干支が甲午の日の時局**を意味すると
判断した。

1ページ（=1見開き）に6局、10ページで60局。各ページの最初の局の日干支を
確認したところ、ページ1＝甲（甲子・甲寅・甲辰・甲午・甲申・甲戌の6局）、
ページ2＝乙、ページ3＝丙、ページ5＝戊、ページ10＝癸、と**10干（甲乙丙丁戊己庚
辛壬癸）が1頁ずつ割り当てられ、各干は自分と陰陽が一致する6支（陽干なら
子寅辰午申戌、陰干なら丑卯巳未酉亥）とだけ組む**ことを確認した。
**これは60干支すべて（10干×6支）が本資料でカバーされていることを意味する。**

### 1.2 局（1日分の表）の構造

1局は、上部の見出し部分と、その下の12時辰マス目で構成される。

- **見出し部分**：局名（「局時日午甲」＝日干支）、方位・煞に関する短い注記
  （「方◯在煞日◯◯沖」＝日の煞の方位とその日の対冲支）、年齢・干支に関する
  数字列（「歳◯◯人◯◯沖正」等）、および右上に複数列の短い語句
  （「散耗物財」「倉開不甲」等）。これらは判読はできるが、擇時計算に直接使う
  ものかどうか資料内で明言されておらず、今回は**構造の存在のみ記録し、意味の
  断定はしない**（推測禁止のため）。
- **12時辰マス目**：2段×6列で12時辰（子丑寅卯辰巳午未申酉戌亥）を配置。
  各マスの見出しは「時◯◯」（例：「時子甲」）で、**時辰の支＋その時の干**を示す。

### 1.3 時辰見出し（時干支）の確認

甲日の12時辰見出しを確認したところ、子＝甲、丑＝乙、寅＝丙、卯＝丁、辰＝戊、
巳＝己、午＝庚、未＝辛、申＝壬、酉＝癸、戌＝甲、亥＝乙、となっていた。これは
**日干から時干を求める五鼠遁（甲己の日は甲子時から起算する）と一致する**
（本資料のデータから直接確認できた事実であり、外部知識で補完したものではない）。
乙〜癸の各局でも同様の時干配列になっているかは全局を悉皆確認していないが、
確認した範囲（甲・乙局）では一貫していた。

**→ 時辰見出し（60日干支×12時辰の「時干支」そのもの）は、五鼠遁の標準式で
機械的に再現可能と判断できる。**

### 1.4 各時辰マスの内部構造

1マスは概ね以下の構成:

1. 4つの小記号の列（●＝黒丸、半分黒半分白の丸、二重丸など）
2. 「沖◯◯」という2文字のラベル（干支1組）
3. 「煞」で始まる短い語句列（複数の神殺名を圧縮表記したもの）＋末尾に連番の数字

(1)の記号の意味、(3)の神殺名の正確な分割・特定は、印字が非常に小さく圧縮
されており、拡大しても一意に確定できない箇所が多い（例：「煞天右三／北刑箭合」
のような4文字×2行の圧縮表記から、個別の神殺名を確実に切り分けることが
できなかった）。**これらは無理に推測復元していない。**

(2)の「沖◯◯」は各マスに共通して存在する明瞭な項目だが、今回機械的な検算を
試みたところ、単純な「六冲（対支）かつ同一干」という一般的な式とは一致しない
組み合わせが見られた（例：時戌甲＝甲戌時に対し「沖戊辰」の表記が見えるが、
六十干支の対冲位置を機械的に計算すると甲戌の対冲は甲辰になるはずで一致しない）。
**この不一致が読み取りの誤りによるものか、時家独自の別の沖の定義によるものかは
今回のスコアプでは確定できなかった。一般的な擇日知識で補完せず、「沖の具体的な
算出式は資料からは確定できない」として保留する。**（ユーザー指示どおり、中央綴じ
部分の判読困難箇所自体の復元は行っていない。この保留は綴じ部分とは別に、
明瞭な箇所の検算不一致によるもの）

## 2. 時家吉神・時家凶神（最終ページの凡例）

11ページ目に「時家吉神析義」「時家凶神註解」の表があり、各神殺について
名称と「宜」（吉神側）または「忌／可否の目安」（凶神側）の短文が記載されている。

箇所があり、正確な神殺の総数は本資料の表記だけからは一意に確定できない）。

**上段10列**：長生帝旺／馬元祿元驛馬／六合五合喜神／三合天大進／羅紋祿貴交馳

## 3. 時家神殺の算出方法

各時家神殺（吉神・凶神とも）について、「何を入力すれば発生を計算できるか」を
確認しようとしたが、**本資料には各神殺の成立条件を明示した記述（例：「◯◯は
日干が甲乙のとき、時支が◯なら成立」のような起例文）が見当たらなかった**。

代わりに本資料が提供しているのは、**60日干支×12時辰の各マスに、その日その時に
成立する神殺名を直接印字した「結果一覧表」**である。つまり、本資料の使い方は
「計算式を適用する」のではなく「該当する局・時辰のマスをそのまま参照する」
という運用を前提にしていると判断した。

3.1節で述べたとおり、各マスの神殺名の圧縮表記は判読が難しく、**720マス（60局×
12時辰）を悉皆で書き起こして規則性を検証する作業は今回のスコープでは行って
いない**（時間対効果、および判読不能箇所を推測復元しないという方針のため）。
したがって、「日干×時支」「日支×時支」「日干支×時支」のいずれの入力で
決まるのかは、**本資料の記述からは確定できなかった**。

参考情報（推測ではなく事実の記録）として、同じ甲日でも日支が異なる2局
（甲午日・甲子日）の「子時」マスを見比べたところ、記載されている神殺名の
圧縮表記が異なっていた。これは**少なくとも日支（またはより広く日干支全体）が
神殺の内容に影響していることを示唆する**が、正確な入力変数の組み合わせを
確定する根拠としては不十分であり、断定はしない。

## 4. 60日×12時辰の構造確認

- 1.1〜1.3節の確認により、**60日干支×12時辰＝720パターンという「マスの構造」
  自体は本資料上に明確に存在し、時辰見出し（時干支）は五鼠遁の標準式で機械的に
  再現可能**であることを確認した。
- しかし、各マスに「どの時家神殺が発生するか」という**中身（神殺名の割り当て）**は、
  本資料では表として直接印字されているだけで、計算式としては確認できなかった
  （3章）。
- したがって、`{ dayStem, dayBranch, hourBranch } → { 時家吉神[], 時家凶神[] }`
  というエンジンを作る場合、**現時点で確実に作れるのは「時辰見出し（時干支）の
  算出」までであり、「時家神殺のリストを返す」部分は、720マス全件を資料から
  正確に書き起こす（表引き）か、追加の一次資料（起例の明文）を確認しない限り
  実装できない**。

## 5. 用事との関係

### 5.1 用事別擇時ができる資料か

本資料は「各時辰にどの時家神殺が成立するか」を示す資料であり、**「修造動土には
この時刻が良い」「嫁娶にはこの時刻が良い」という用事別の直接的な擇時表では
ない**。ただし、2.1節の時家吉神析義の「宜」欄には、擇日で使われるのと同じ
用事語彙（嫁娶・移徙・開市・祈福・求嗣・上官赴任・造葬など）が神殺ごとに
列挙されており、**「この時家神殺が成立している時辰は、これらの用事に良い」
という間接的な対応関係は資料から読み取れる**。

つまり、擇時における用事判定の構造は、擇日（日家）と同じ**「神殺→宜用事の
対応表」というパターンを踏襲している**可能性が高いが、それを実際に使うには
3章で確認できなかった「どの時家神殺がいつ成立するか」の算出（または表引き）が
先に必要になる。

### 5.2 現行95 ActivityDefinitionとの接続

時家吉神析義の「宜」欄に現れた用事語彙のうち、現行の95件と**文字列として
直接一致すると確認できたもの**（推測なし、原典表記の完全一致のみ）:

- 嫁娶、移徒（移徙の異体字の可能性、要確認）、祈福、求嗣、開市、上官赴任、
  祭祀、入宅、造葬（→安葬に近いが別語のため断定しない）、修造

これらは擇日エンジンの`ACTIVITY_DEFINITIONS`と同じ表記が使われているため、
**将来的に時家神殺の発生が確定できれば、既存のActivityDefinition idへ
接続できる可能性がある**。ただし今回は算出方法自体が確定していないため
（3章・4章）、**接続の実装は保留する**。

時家凶神註解側の可否短文（「忌上官出行」「忌造船」等）にも同様に
既存の用事語彙が使われているが、凶神側は擇日の「忌」欄のような明確な
リスト構造ではなく、短い可否コメント文であり、**機械的な忌用事リストとしての
抽出は今回できなかった**。

## 6. 擇日との関係

- 本資料は**擇日（日家）の神殺・十二建除・二十八宿・resolution・洪氏錦嚢とは
  独立した別資料**であり、両者を結びつける記述は本資料内に見当たらなかった。
- 2.1節で述べたとおり、時家の「六黄道」的な列見出し（青龍黄道・明堂黄道等）が
  日家の六黄道と同名で存在するが、**同一ロジック・同一解除規則であるとは
  判断していない**（ユーザー指示どおり）。
- 日家のresolution（解除・軽減・増悪）規則を時家へ流用する根拠は本資料に
  存在しないため、**流用しない**。

## 7. 「冲」の扱い

- 書籍中央（綴じ部分）の判読困難箇所は、ユーザーの事前情報のとおり「冲」に
  関する表記として扱い、判読・復元を試みていない。
- 一方、各時辰マスの左寄り（綴じ部分ではない、明瞭に読める範囲）に「沖◯◯」
  という2文字の表記が毎マス存在することを確認した。これは判読自体は可能だが、
  1.4節で述べたとおり、標準的な六冲の計算式と機械検算で一致しない例があり、
  **正確な算出規則は資料からは確定できなかった**。中央の欠損部分だけを根拠に
  新しい規則を作ることはしていない（欠損部分は今回参照していない）。

## 8. 実装可能性の分類

| 評価対象 | 判定 | 理由 |
|---|---|---|
| 時家神殺の算出（`{dayStem,dayBranch,hourBranch} → 神殺[]`） | **D** | 成立条件の計算式が資料に見当たらない。720マスの表引きも、圧縮印字が判読困難で悉皆確認できていない |
| 時辰ごとの吉凶表示（時辰見出し＝時干支の算出のみ） | **A**（この部分のみ） | 五鼠遁の標準式と本資料のデータが一致することを確認済み。ただし「吉凶」そのものの表示は上記の理由でD |
| 用事別の擇時 | **D** | 5.1節のとおり、神殺の発生が確定しない限り成立しない（構造は存在するが算出根拠がない） |
| 現行95用事との接続 | **D**（用語レベルでは重なりを確認、接続実装は保留） | 用事語彙の一致は複数確認できたが、時家神殺自体の算出ができないため接続できない |

総合すると、**時辰見出し（時干支）の機械算出だけはA相当で確実に再現できるが、
時家吉神・凶神の発生判定、用事別擇時、95用事との接続は、いずれも現時点の
資料読み取り精度ではD（資料不足で実装不可）**と判定する。今後もし実装を
進めるなら、(a) 720マスの神殺名を圧縮表記から一つずつ正確に書き起こす作業、
または (b) 各時家神殺の成立条件を明文で説明した別の一次資料の確認、のいずれかが
必要になる。
