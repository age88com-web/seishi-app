初回監査では「37語」との認識違いがあり、実際は宜28・忌19の延べ47件（ユニーク40語）と判明した。その後、D・F分類の13語についてユーザーが`docs/source/時家吉凶.pdf`原本を再確認した結果、以下が判明した。
