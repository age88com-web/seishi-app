# 剋應（こくおう）モジュール

奇門遁甲の剋應（予兆）を、算出済みの盤情報から参照データで引くだけの薄い層。
排盤ロジック（CalendarEngine / qimenEngine）・七政四餘は一切変更しない。
`calculate()` の戻り値 `QimenResult` のみを入力とする。

## データの出所

`data/*.json` は `docs/source/kokuoo/` の資料を**検証転記した検証専用 fixture**であり、
機械的にコピーしただけで内容は一切改変していない。

| ファイル | 原本 | 件数 |
|---|---|---|
| `data/jikkan.json`        | `docs/source/kokuoo/剋應_十干剋應81件.json`     | 81  |
| `data/hachimon.json`      | `docs/source/kokuoo/剋應_八門剋應200件.json`    | 200 |
| `data/kyusei_jichi.json`  | `docs/source/kokuoo/剋應_九星値時剋應218件.json`| 218 |
| `data/sanki_tokyu.json`   | `docs/source/kokuoo/剋應_三奇到宮剋應24件.json` | 24  |

唯一の仕様根拠は上記資料（元は門外不出資料由来の正式データ）。
一般書・他流派・推測での補完は禁止。

## 検索仕様（正式）

| 系統 | 検索キー | 備考 |
|---|---|---|
| ① 十干剋應          | 天盤奇儀 × 地盤奇儀        | 甲は資料どおり戊へ正規化 |
| ② 八門剋應（門×門） | 人盤八門 × 地盤八門（後天定位門） | 静應・動應の両方を返す |
| ③ 八門剋應（門×三奇）| 人盤八門 × 天盤奇儀       | 天盤奇儀が乙・丙・丁のときのみ |
| ④ 三奇到宮剋應      | 地盤三奇（乙丙丁）の宮 × 八宮名 | 天盤ではなく地盤基準 |
| ⑤ 九星値時剋應      | 値符星 × 時支             | クリック宮に値符星があるときだけ |

- 地盤八門（後天定位門）: 坎休・坤死・震傷・巽杜・乾開・兌驚・艮生・離景
- 中宮(5): 剋應は検索しない（すべて「—」）。既存の宮詳細が中宮の天盤干・八門を
  「—」表示しているのと整合させる。
- 該当が無ければ空配列（UI 側で「—」表示）。
- 複数典拠・複数レコードに合致する場合は全件返し、優先順位を付けない。
